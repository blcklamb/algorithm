# 폴더 구조

```
├──_basic
│  : 문제 풀이와 관련없는 코드들
│  ex. nodejs input, 효율성 계산기
└──_history
   : 지난 문제 풀이 (1년 이상 지난 것)
       ├──javascript   (2023.07.18 이전)
       ├──python       (2023.07.18 이전)
       └──YY-MM        (첫 커밋 월 기준, ex. 23-08)
           ├──백준/{티어}/{문제}
           ├──프로그래머스/{레벨}/{문제}
           └──leetcode/{문제}
```
